# Eye Lab

Physically calibrated binocular vision, accommodation and visual function tests for a laptop, monitor or Android tablet.

- **Android app:** download `EyeLab.apk` from the latest release on the Releases page and open it on the tablet (allow installs from your browser or file manager when asked). It runs full screen with no browser bars or "full screen" notice, and asks for the camera only for the camera tests.
- **Web app:** the GitHub Pages site can be installed from Chrome's menu (Install app / Add to home screen) and also opens full screen.

`index.html` is the whole app. `build_index.py` rebuilds it from the single-file version.
Every push to `main` rebuilds the APK and the site.
